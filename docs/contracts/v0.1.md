# Canonical episode contract v0.1

Status: **frozen** from the `contract-v0.1` Git tag.

The normative interface is `contracts/v0/schema.json`; the adjacent
`schema.sha256` detects silent edits. A canonical episode is one directory with
an `episode.json` manifest and relative `.npy` artifacts. Every array is aligned
on dimension zero to the strictly increasing nanosecond timestamp vector.

## Tensor conventions

| Field | Shape | Type | Meaning |
|---|---:|---|---|
| timestamps | `[T]` | `int64` | aligned sample time in the declared clock |
| RGB | `[T,H,W,3]` | `uint8` | RGB channel order |
| depth | `[T,H,W]` | `float32` | optical-axis depth in metres |
| joint position | `[T,J]` | `float32` | radians, ordered by `robot.joint_names` |
| joint velocity | `[T,J]` | `float32` | radians/second, same order |
| gripper position | `[T,1]` | `float32` | finger opening width in metres |
| action | `[T,J+1]` | `float32` | target joint positions then gripper width |

Camera intrinsics are the row-major pinhole `K` matrix. Extrinsics are the
row-major homogeneous transform `T_parent_child`; translations are metres.

## Compatibility and changes

No producer may change `contracts/v0/schema.json` without all of:

1. an interface-change note in `docs/contracts/changes/` describing migration,
2. a version bump and a new schema path when compatibility is broken,
3. regenerated fixtures and validators, and
4. an updated digest reviewed in the same commit.

Adding data outside `episode.json` is allowed. Adding manifest properties is
not backward-compatible because objects intentionally use
`additionalProperties: false`.

Validate an episode with:

```bash
PYTHONPATH=src python3 -m embodiedflow.contracts.validator samples/episode_v0/episode.json
```
